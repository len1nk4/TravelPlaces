# TravelPlaces11 – Места за посещение

Учебен проект по Интернет програмиране с ASP.NET Core MVC, Entity Framework Core и SQL Server. Приложението съхранява туристически обекти: име, област, вид, входна такса и описание. Входната такса не може да е отрицателна.

## Функционалност

- Списък с туристически обекти със средна оценка от отзивите.
- Търсене по име.
- Филтриране по вид.
- Добавяне на обект с валидация (името, областта и видът са задължителни, таксата е ≥ 0).
- Страница с детайли и отзиви за всеки обект.
- Добавяне на отзив (оценка от 1 до 5, коментар, дата на посещение).
- Демо данни при стартиране в режим Development.

## Ентитита

| Ентити | Описание |
| --- | --- |
| `Area` | Област (28-те области на България). |
| `PlaceType` | Вид обект: музей, крепост, манастир и др. |
| `TravelPlace` | Туристически обект: име, област, вид, такса, описание. |
| `Visitor` | Посетител: име и имейл (уникален). |
| `Review` | Отзив на посетител за обект: оценка, коментар, дата. |

Връзки:

- Една `Area` има много `TravelPlace`.
- Един `PlaceType` има много `TravelPlace`.
- `TravelPlace` и `Visitor` са свързани „много към много“ чрез `Review`.

Ограничения в базата: `Fee >= 0` и `Rating` между 1 и 5 (check constraints), уникални имена на области и видове, уникален имейл на посетител.

## Архитектура

| Проект | Зависи от | Предназначение |

| `TravelPlaces11.Web` | Services, Data | Контролери, ViewModel-и и Razor изгледи. |
| `TravelPlaces11.Services` | Data | `PlaceService` и `LookupService`, DTO-та. |
| `TravelPLaces11.Data` | — | Ентитита, `TravelPlaces11DbContext`, миграции, демо данни. |

## Стартиране

1. Проверете connection string-а в `TravelPlaces11/appsettings.json`.
2. В Package Manager Console изпълнете `Update-Database -Project TravelPLaces11.Data -StartupProject TravelPlaces11.Web`.
3. Стартирайте `TravelPlaces11.Web`.
